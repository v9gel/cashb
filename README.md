# cashb

Веб-приложение для аналитики кэшбэка

## Как запустить

Для установки зависимостей:

```bash
bun install
```

Для запуска:

```bash
bun run dev
```

## Возможности

- [x] Добавление торговых точек (магазины, кафе, сервисы, и тд)
- [x] Добавление банковских карт
- [x] Заполнение кэшбэка на текущий месяц
- [x] Подбор оптимальной карты для оплаты в конкретной торговой точке
- [x] Добавление значка приложения на домашний экран
- [x] Вывод последних просмотренных торговых точек
- [x] Вывод последних добавленных торговых точек
- [ ] Вывод ближайших торговых точек
- [ ] Напоминание о выборе кэшбэка в конце месяца
- [ ] Шаринг торговых точек между пользователями (все данные в url)
- [ ] Автоматическая рекомендация по выбору категорий кэшбэка среди доступных в новом месяце
- [ ] Онбординг
- [ ] Возможность добавления пользователем новых банков и редактирование категорий кэшбэка в них
